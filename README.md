# ◈ BEL-TrustNet

### Blockchain-Based Identity & Asset Handover Verification Platform

**Identity → Permission → Physical Asset → Verified Handover → Audit**

BEL-TrustNet is a blockchain-oriented prototype designed to improve identity verification, access control, digital asset registration and accountable physical asset handovers.

The platform demonstrates how decentralized identity concepts, role-based authorization and digital asset records can work together to create a transparent and traceable asset management system.

 📌 Key Features

- **Identity Verification:** Demonstrates DID-lite identity verification and wallet-linked roles.
- **Asset Registry:** Represents digital and physical assets through NFT-style records.
- **Physical-Digital Verification:** Demonstrates cross-checking physical identifiers against digital asset records.
- **Role-Based Access Control:** Demonstrates permission-based asset transfer authorization.
- **Liveness & Time-Bound Access:** Includes simulated liveness checks and access leases.
- **Audit Trail:** Displays a prototype representation of asset-related security events.

 🏗️ System Architecture

The proposed system follows five major layers:

1. Identity – IdentityRegistry
2. Access – AccessControlManager
3. Asset – AssetRegistry
4. Verification – Physical-to-digital asset matching
5. Audit – Event-based accountability

 🛠️ Technology Stack

- Blockchain: Polygon Amoy (proposed integration)
- Smart Contracts: Solidity, OpenZeppelin
- Decentralized Storage: IPFS / Pinata
- Frontend: HTML, CSS, JavaScript
- Blockchain Integration: Ethers.js (planned integration)
- Wallet: MetaMask (planned integration)

 ⚙️ Current Prototype Status

The currently deployed website is an interactive frontend prototype. It uses JavaScript-based simulated system states to demonstrate the proposed workflows. The displayed blockchain and smart-contract architecture represents the intended production design, not a fully connected live blockchain implementation.
